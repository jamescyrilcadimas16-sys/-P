Publish the actual website

This updates index.html in your GitHub repository and uploads new media into assets/. Create a fine-grained token restricted to this repository with Contents: Read and write. The token is not saved. Never share this page while a token is filled in.

Security: The PIN is visible in source code and is only a convenience gate. The GitHub token is powerful; use a fine-grained token for this one repository and revoke it after use if appropriate. For true administrator security, use a backend.
